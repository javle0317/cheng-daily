# 體組成（健康頁 → 體組成 →「貼上匯入」）

使用者的體脂計是 Tokuyo，App 的「測量結果」截圖會分好幾張，數字都在上面。

```json
{ "date": "2026-10-07", "values": { "weight": 113.3, "height": 175, "bodyFat": 39.0, "fatMass": 44.2, "skeletalMuscle": 35.1, "muscleMass": 66.0, "bodyWater": 45.0, "protein": 14.2, "bmr": 1900, "visceralFat": 18, "bodyAge": 50, "whr": 0.98 } }
```

## 欄位對照（截圖上的名稱 → 鍵）
| 鍵 | 截圖上的項目 | 備註 |
|---|---|---|
| `weight` | 體重（kg） | **必填** |
| `height` | 身高（cm） | 截圖通常沒有，**省略**（App 會沿用上次的） |
| `bodyFat` | 體脂率（%） | 不是「體脂肪量」 |
| `fatMass` | 體脂肪量（kg） | |
| `skeletalMuscle` | 骨骼肌重（kg） | 不是「骨骼肌率」 |
| `muscleMass` | 肌肉量（kg） | 不是「肌肉率」 |
| `bodyWater` | 身體水分量（**kg**） | 不是「身體水分率」% |
| `protein` | 蛋白質量（kg） | 不是「蛋白質率」 |
| `bmr` | 基礎代謝率（kcal） | |
| `visceralFat` | 內臟脂肪 | |
| `bodyAge` | 身體年齡 | |
| `whr` | 推測腰臀比 | 截圖精度可能只有一位小數，照給 |

沒有對應欄位、**不要放進去**：骨量、去脂體重、BMI（App 用體重和身高自己算）、心率、皮下脂肪、各部位脂肪、肥胖程度、健康評分、建議攝取熱量等。

## 日期：先問，不要自己填（為什麼：記錯日期會多出一天的紀錄，還會讓「週活動」自動多打一次卡）
- 體脂計截圖**只有手機時間、沒有測量日期**。使用者沒有明確說是哪一天，**先問一句「這是哪一天量的？」再給 JSON**，不要直接填今天。也不要因為使用者丟的是截圖就假設是今天量的，可能是舊的截圖。
- 使用者說「今天」「剛量的」才可以填今天的日期；說了具體日期就用那個日期。
- 使用者堅持先給、沒有回答日期時，才把 `date` **整個省略**（App 的表單會維持預設的今天，使用者核對時看得到、可以改），並在回覆裡明講「日期我沒填，請在表單裡確認」。**不要自己猜一個日期放進 JSON。**

## 其他提醒
- 同一個人在條件一致下量出來的差異，不要過度解讀；電阻式體脂計的肌肉、體脂估算本來就會晃動，看連續幾次的趨勢比單次準。不要做醫療判斷。

貼到：健康頁 → 體組成 → ＋ 新增 →「貼上匯入」→「填入表單」→ 核對後按「新增」。
