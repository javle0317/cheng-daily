# 食譜（飲食頁 → 食譜 → ＋ 新增食譜 →「貼上匯入」）

使用者傳食譜網頁、截圖或文字時，整理成這個格式。匯入只會把內容**填進表單**，核對後按「新增」才送出（一次一道）。評分與煮過次數不在匯入範圍（在 App 裡記）。

```json
{ "name": "滷肉飯", "tags": ["主菜", "台式"], "ingredients": ["五花肉 600g", "醬油 80ml"], "steps": ["五花肉切丁炒香", "加醬油與水滷 40 分鐘"], "notes": "可加滷蛋" }
```

## 規則
- `name` 必填（≤100 字）。
- `tags`：字串陣列（或逗號分隔字串），每個 ≤20 字、最多 10 個；優先沿用已有的標籤（主菜、湯、點心、早餐、低醣…）。
- `ingredients`、`steps`：字串陣列，**一項一個元素**；食材帶份量與單位（`雞胸肉 300g`）；步驟**不要自己加編號**。
- `notes`：選填（小訣竅、出處）。
- **單位、份量照原文，不要擅自換算**。來源沒寫、你不確定的就省略，不要編造。

貼到：飲食頁 → 食譜 → ＋ 新增食譜 →「貼上匯入」→「填入表單」→ 核對後按「新增」。
