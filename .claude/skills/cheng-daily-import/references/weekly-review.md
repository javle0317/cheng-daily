# 每週健康摘要分析（使用者貼來【每週健康摘要】時）

這**不是匯入 JSON**，而是解讀：使用者從健康頁「今日 → 每週回顧」按「複製本週摘要」，貼一段純文字（週一到週日的體重、睡眠、飲食、運動、血壓數字）給你。你要看懂這週、指出最值得改的 1～2 件事，最後給一段可貼回「教練備註」的文字。

## 分析步驟（照順序，為什麼：資料不夠就下結論，會讓使用者做錯的調整）

1. **先看資料夠不夠**，列出這週的缺口（體重量了幾次、睡眠記幾天、「記完」的飲食天數）。
   - 體重少於 3 次、或「記完」的天數少於 4 天：**只講資料不足與怎麼補，不下熱量或體重的結論**。
   - 摘要裡「未記錄」就是沒資料，**不是 0**，也不要幫他補。
2. **體重看 7 日平均的變化，不看單日**。每週平均下降 0.25–0.5 kg 是目標；單週 ±1 kg 常是水分、鹽分（外食、buffet、打完球的隔天），先不要解讀成失敗或成功。
3. **反推實際消耗（兩週以上才做）**：取連續兩週「記完」的天數，實際每日消耗 ≈ 平均每日熱量 +（體重平均每天下降的 kg × 7700）。
   - 記完的天數兩週合計少於 8 天：不要算，告訴他還差幾天。
   - 算出來和目前的每日參考（約 2,200 kcal）差超過 200 kcal 才建議調整，並且一次只調 100–200 kcal。
   - 所有熱量都是照片估計（±20%），結論要講「估計範圍」，不要講單一精準數字。
4. **睡眠**：平均時數、平均上床與規律度、打瞌睡天數、CPAP 有沒有戴。只描述，不診斷；使用者有高血壓與睡眠呼吸中止症，CPAP 沒戴或血壓偏高多的週，**建議問醫師**，不要自己下醫療判斷。
5. **運動**：打球次數與分鐘、有沒有其他低衝擊運動。使用者有反覆足底疼痛，不要建議增加高衝擊運動；運動消耗只是參考，**不要叫他把消耗吃回來**。
6. **找最多 2 個可行的改變**（具體、小步、這週就能做）。沒有明顯問題就說「照現在的節奏」，不要為了有建議而湊建議。
7. 只談相關、不談因果（例如「睡得少的那幾天熱量也比較高」是觀察，不是原因）。語氣不要責備，漏記一天不是失敗。

## 回覆的樣子

1. 一段 3～5 行的**這週重點**（先講資料夠不夠）。
2. 最多 **2 個建議**。
3. 一個可貼回的 **教練備註**（純文字、150 字以內、只有日期與結論，不含姓名等個人資料），用 ``` 包起來讓他好複製，結尾註明「下週要看：…」。

貼回：健康頁 → 今日 → 每週回顧 →「教練備註」→「儲存備註」。
