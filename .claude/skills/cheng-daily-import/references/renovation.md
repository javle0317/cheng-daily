# 裝潢報價（裝潢頁 → ＋ 匯入報價）

使用者在做裝修，會丟設計師／廠商的報價單（截圖、PDF 文字、LINE 對話）。**一次一個商家**；同一商家之後再來一輪議價，就再整理一份新的 JSON 匯入。App 依「商家＋品項名稱」比對：沒有就新增（第 1 輪）、價格或數量有變就更新並記下一輪 history、完全沒變就略過。

```json
{ "vendor": "某某室內設計", "date": "2026-10-20", "note": "第二輪議價", "items": [ { "name": "系統櫃（客廳電視牆）", "qty": 3.2, "unit": "尺", "listPrice": 8500, "dealPrice": 7600, "note": "含安裝" }, { "name": "木地板", "qty": 18, "unit": "坪", "listPrice": 4200 } ] }
```

## 欄位
- `vendor`：**必填**，商家／設計師名稱。**同一家每次都要寫一模一樣**（比對靠這個），沒把握就問使用者之前用哪個寫法。
- `date`：**必填**，這份報價的日期 `yyyy-MM-dd`（報價單上的日期；沒有就問使用者，不要用今天湊）。
- `note`：選填，這一輪的說明（「第二輪議價」「含運」），沒有逐項備註的品項會記這句到 history。
- `items[]`：
  - `name`：**必填**。**同一商家同一品項每次都要寫一樣**，不然會被當成新品項。照報價單原文，不要自己改寫、合併、拆分。
  - `qty`：數量，省略 = 1。照報價單（可以是小數，例如 3.2 尺）。
  - `unit`：單位（尺、坪、組、式、片…），選填。
  - `listPrice`：**單價**原價。`dealPrice`：**單價**優惠價／成交價。**兩個至少要有一個**（可為負數，只給折讓類品項用）；只有一個價格就只填那一個（沒有優惠就只填 `listPrice`；報價單只寫成交價就只填 `dealPrice`）。
  - `note`：這個品項的備註（含安裝、材質、規格），選填。
  - `status`：選填，`quoted`（報價中，預設）／`signed`／`paid`／`dropped`。**使用者沒說就不要填**。
- **價格是單價**：App 小計＝數量 × 單價。報價單上如果只給「總價」（例如「系統櫃 一式 85,000」），就 `qty: 1`、`unit: "式"`、價格填那個總價；如果報價單同時有單價、數量、小計，填單價與數量，並檢查小計對不對得上，對不上要列出來給使用者。
- 稅、運費、折讓、整單折扣：能歸到品項就歸（寫在備註）；歸不進去的就當成獨立品項，例如 `name: "整單折讓"`、`qty: 1`、`dealPrice: -10000`（價格可以填**負數**，才能從總額扣掉）。不確定怎麼處理就列出來問使用者。
- 金額不要抄的：報價單上的統編、地址、電話、帳號、客戶姓名。

貼到：裝潢頁 → ＋ 匯入報價 → 貼上 →「檢查並匯入」→ 確認視窗會列出新增幾項、哪些價格有變（舊 → 新）。
