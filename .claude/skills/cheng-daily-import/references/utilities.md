# 水電瓦斯帳單（帳單頁 → 水電瓦斯 → ＋ →「批次貼上匯入」）

可以一次很多筆（上限 150）；有任何一筆有問題整批都不會匯入。

```json
{ "items": [ { "type": "electric", "billingMonth": "2026-08", "months": 2, "amount": 3600, "usage": 800, "note": "" } ] }
```

## 欄位
- `type`：只能是 `water`（水費）、`electric`（電費）、`gas`（瓦斯）。網路、電信、訂閱先不記。
- `billingMonth`：`yyyy-MM`，是帳單上**計費期間結束的月份**（通常就是帳單上的「收費年月」，民國年換西元：115 年 08 月 = 2026-08）。沒寫清楚就問，不要猜。
- `months`：計費月數（1–12）。台灣水電與台北瓦斯都是**兩個月一期（2）**；帳單上有寫計費期間就以它為準；沒給時 App 預設 2。
- `amount`：帳單上的**應繳總金額**（純數字）。
- `usage`：用量（度，純數字）。沒印就省略。
- `note`：選填，不要編造；最多 100 字。
- **金額與用量至少要有一個**。
- **同一類型同一個月份不能出現兩次**；已經記過的月份會被更新。

## 各種帳單怎麼讀
- **水費單**：用量用「**總用水度數**」（含本戶分攤的公共用水，用水費是依它算的；帳單底下「前 6 期用水度數」那排也是總度數）。金額用「應繳總金額」。
- **電費單**：用量用「**經常度數**」（計費度數；不是「底度」也不是「公共分攤戶數」）。可以用「流動電費計算式」各級距度數加總、以及帳單印的「當期每度平均電價」交叉驗證。
- **瓦斯單**：用量用「本期計費度」（本期累計度 − 上期累計度）。`amount` 若含**設備費**（安全龍頭、設備更換等）或其他非用量費用：`amount` 只記用量相關的費用（基本費＋從量費＋調整價差），設備費寫進 `note` 並註明帳單應繳總額，這樣月均與每度單價才不會失真，並在回覆裡跟使用者說明這個決定。
- **帳單附註的歷史用量**：瓦斯單有「去年同期計費度」、水費單底下有前 6 期用水度數。這些**只有用量沒有金額**，可以只給 `usage`、省略 `amount`（`billingMonth` 用那一期的收費年月，`months` 先用 2），App 會標示「只有用量」並用在用量圖與「去年同月」。要先確認該月份使用者還沒記過完整帳單，免得被覆蓋（已有的月份只補空白欄位以外會被更新）。
- 帳單上的姓名、地址、電號、水號、用戶號碼等**不要抄進去**。

貼到：帳單頁 → 水電瓦斯卡片右上「＋」→ 彈窗最上面「批次貼上匯入」→「檢查並匯入」→ 確認筆數。
