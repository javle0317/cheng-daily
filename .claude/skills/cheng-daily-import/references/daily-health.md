# 今日健康（健康頁 → 今日 →「貼上匯入」）

使用者在減重期間每天記睡眠、體重、餐點。他會傳**餐點照片**（有時加上「幾點睡、幾點起、體重多少」的文字），你要估熱量與蛋白質，整理成**一天一份** JSON。

```json
{
  "date": "2026-11-11",
  "weight": 109.4,
  "sleep": { "bedtime": "01:30", "sleepTime": "01:50", "wakeTime": "08:40", "quality": 3, "energy": 6, "cpap": "yes", "nap": false, "note": "半夜醒一次" },
  "mealsComplete": true,
  "exercise": [
    { "type": "pickleball", "minutes": 120, "rpe": 7, "kcal": 450, "note": "6 人一面場" }
  ],
  "meals": [
    { "meal": "breakfast", "desc": "無糖豆漿、蛋餅", "kcal": 380, "protein": 18 },
    { "meal": "lunch", "desc": "雞腿便當（飯半碗）", "kcal": 720, "protein": 38, "eatOut": true },
    { "meal": "snack", "desc": "珍奶半糖", "kcal": 350, "sugarDrink": true }
  ]
}
```

## 欄位
| 鍵 | 說明 |
|---|---|
| `date` | 西元 `yyyy-MM-dd`。**睡眠的日期是「起床那天」**（昨晚 01:30 睡、今天 08:40 起 → 填今天）。使用者沒說是哪一天就先問 |
| `weight` | 體重 kg（數字）。體重照片只用來讀數字；沒給就省略 |
| `sleep.bedtime` / `wakeTime` | `HH:mm` 24 小時制，**兩個要一起給**，只有一個就整段 sleep 省略並問使用者 |
| `sleep.sleepTime` | 實際入睡時間，選填；不知道就省略（不要拿上床時間填） |
| `sleep.quality` | 1–5；`sleep.energy` 白天精神 1–10；都是使用者主觀說的，沒說就省略 |
| `sleep.cpap` | `"yes"` 或 `"no"`，沒說就省略；`sleep.nap`：有打瞌睡才 `true` |
| `mealsComplete` | 使用者說「今天都記完了／沒有漏拍」才寫 `true`；不確定或有餐沒拍就省略（**沒標記記完的日子不會納入每日熱量平均**）。真的某餐沒吃就省略那餐、仍可標 `true` |
| `exercise[].type` | `pickleball` / `lowimpact`（腳踏車、游泳）/ `strength` / `walk` / `other`；`minutes` 必填整數，`rpe` 1–10、`kcal`、`note` 選填 |
| `meals[].meal` | `breakfast` / `lunch` / `dinner` / `snack`（點心可以有多筆，其他餐別一天一筆） |
| `meals[].desc` | 吃了什麼，簡短（必填） |
| `meals[].kcal` / `protein` | **估計值**，數字；真的估不出來就省略，**不要填 0** |
| `meals[].eatOut` / `sugarDrink` | 外食、含糖飲料才寫 `true`，其餘省略 |

## 估算的規矩（為什麼：使用者是要用這些數字判斷為什麼沒瘦，估太樂觀會讓他誤判）
- 看照片估份量時**寧可估高一點**：油、醬、勾芡、飲料糖、肉的皮和肥，不確定就往高的那邊估。
- 在回覆裡寫每餐的估算依據（例如「便當：飯約 150g、雞腿約 150g 去骨」），並標明誤差大約 ±20%，讓使用者能修正。
- 看不清楚的餐、被擋住的食物，**列出來問**，不要猜；沒拍到的餐別就省略，不要補。
- 不要做營養或醫療建議，只給數字與依據。使用者有高血壓、睡眠呼吸中止症，這些是他的醫療範圍，不要評論。
- 沒有照片、只有口述的餐，照樣估，但依據欄寫「口述估算」。

## 特殊情況怎麼估
- **兩人份共食、有剩**：使用者通常點兩人份、他多吃一些。先看照片估「整桌總量」，再問「你吃了大概幾成、剩多少」；他沒說就**預設他吃 55%**，剩下沒吃的先扣掉再算，並在依據欄寫明「假設吃 55%、剩 X」。`desc` 寫他吃的那份（例如「牛肉麵（共食，約吃 55%）」）。
- **Buffet／吃到飽**：使用者會每一輪夾菜拍一張，包含飲料、甜點。把每輪加總成**一筆**（通常歸 `lunch` 或 `dinner`），`eatOut: true`；吃到飽人人都會低估，**每道菜寧可估高**，依據欄列每輪的估算，並提醒誤差大（±30%）。度假期間數字粗一點沒關係，趨勢才重要。
- **少拍了一餐**：不要補，也不要自己把 `mealsComplete` 設 `true`；問使用者那餐是沒吃還是忘了拍。
- **打球**：6 人一面場、2 小時，實際跑動約一半時間，以他約 110 kg 粗估消耗約 **450 kcal**（範圍 350–600）；`type: "pickleball"`、`minutes: 120`、`rpe` 問他（沒說就省略）。運動消耗只是參考，**不要叫他把消耗吃回來**，也不會加進每日熱量預算。

貼到：健康頁 → 今日 →「貼上匯入」→「填入表單」→ 核對後按「儲存」。同一天已有紀錄時，送出的睡眠與餐別會覆蓋舊的，沒送出的餐別不動。
